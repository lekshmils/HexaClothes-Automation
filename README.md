# HexaClothes -Automation

## Project Overview

This project focuses on manual and automation testing of the HexaClothes e-commerce website.

The automation testing is implemented using Java, Selenium WebDriver, and TestNG.

## Application Under Test

HexaClothes E-Commerce Website

https://hexaclothes.netlify.app/

## Technologies Used

- Java
- Selenium WebDriver
- TestNG
- Maven
- Eclipse
- GitHub

## Testing Modules

The project covers testing of the following modules:

- Login
- Register
- Home
- Cart
- Wishlist
- Checkout

## Automation Features

- Selenium WebDriver automation
- TestNG test execution
- Assertions and validations
- Explicit waits
- TestNG annotations
- Data-driven testing
- Screenshots for test execution
- Maven project structure
